# Viresh Ranjanagi | Portfolio

Clean, responsive personal portfolio showcasing web development skills, projects, and experience.

**Live Demo:** [Veeresh-Portfolio](https://veereshr4446.github.io/Veeresh-Portfolio/)

---

## Overview

This is my personal portfolio website built with vanilla HTML, CSS, and JavaScript. It presents my skills, projects, education, certifications, and contact information in a clean, readable format.

---

## Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Custom properties, flexbox, grid, responsive design
- **JavaScript (ES6)** – Form handling
- **Google Fonts (Inter)** – Typography

---

## Features

| Section | Content |
|---------|---------|
| **Header** | Name, title, social links (GitHub, LinkedIn, Email) |
| **Bio** | Brief introduction and focus areas |
| **Skills** | Mobile, Frontend, Programming Languages |
| **Projects** | 4 projects with tech tags |
| **Education** | Timeline with progress indicators |
| **Certifications** | 6 certifications with dates and descriptions |
| **Achievement** | Scaler School of Technology × BITS Pilani selection |
| **Contact** | Email, location, LinkedIn + contact form |

---

## Key Design Choices

| Choice | Reason |
|--------|--------|
| **Dark theme** | Modern, readable, reduces eye strain |
| **Gradient accents** | Visual interest without clutter |
| **Card-based layout** | Clean separation of content |
| **Responsive grid** | Works on all screen sizes |
| **Single file per type** | Easy to maintain and review |
| **No frameworks** | Shows understanding of fundamentals |
